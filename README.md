# Intelligent Document Processing

A public-safe automation demo for extracting structured invoice/PO fields, scoring confidence, matching documents, and routing exceptions for human review.

## Demonstrates
- document field extraction patterns
- invoice / PO matching
- confidence scoring
- duplicate detection
- exception queues
- approval controls
- structured outputs for downstream ERP/accounting workflows

All documents and values are synthetic.

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```
